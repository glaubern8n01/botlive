# Pesquisa técnica

Pesquisa clean-room em 2026-08-08. Material de Live Infinite/Loopyz foi tratado como alegação comercial; nada foi copiado.

O Partner Center documenta APIs de vendedor, produtos, pedidos, logística, finanças e webhooks, mas as fontes públicas consultadas não comprovam API geral para iniciar LIVE, ler todo chat ou fixar produto. Essas ações ficam manuais ou `UNVERIFIED`.

Fontes: [Developer Guide](https://partner.tiktokshop.com/docv2/page/tts-developer-guide), [Products API](https://partner.tiktokshop.com/docv2/page/products-api-overview), [LIVE Shopping](https://business.tiktokshop.com/us/creator/live), [guia de criação](https://seller-us.tiktok.com/university/course?content_id=7218816540444418&lang=en&learning_id=84434503206657), [Guidelines](https://www.tiktok.com/community-guidelines/en/accounts-features), [OBS WebSocket](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md).
