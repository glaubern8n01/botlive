# Modelo de ameaças

Ativos: catálogo, roteiro, eventos, métricas e futuros tokens oficiais. Ameaças: credenciais, WebSocket de origem indevida, XSS, PII, replay de pareamento e automação incompatível com a plataforma.

Controles: simulação padrão; nenhuma senha/cookie; payload validado; origens explícitas; token local comparado em tempo constante para HTTP e WebSocket; token mantido apenas em `sessionStorage` no dashboard; logs mínimos; integração real bloqueada. A autenticação só pode ser desativada explicitamente em testes controlados. DOM automatizado, ocultação de alertas, live gravada como real, voz sintética como apresentador e engajamento falso são proibidos.
