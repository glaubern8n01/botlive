# Modelo de ameaças

Ativos: catálogo, roteiro, eventos, métricas e futuros tokens oficiais. Ameaças: credenciais, WebSocket de origem indevida, XSS, PII, replay de pareamento e automação incompatível com a plataforma.

Controles: simulação padrão; nenhuma senha/cookie; payload validado; origens explícitas; logs mínimos; consentimento para câmera/microfone/gravação; integração real bloqueada. DOM automatizado, ocultação de alertas, live gravada como real, voz sintética como apresentador e engajamento falso são proibidos.
